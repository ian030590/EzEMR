# 虛構示範病歷 / Fictional demonstration records

本資料夾包含八位完全虛構的個案：中風、腦傷、複視、單側視覺受損、視野受損、忽略、動作障礙及脊髓損傷。每位都有基準評估、復健及療程後評估，共 24 次病歷，附 CSV、PDF、TXT，可用來練習 EzEMR 的使用。內容不是診療建議。

1. 用桌面版 Chrome 或 Edge 開啟上層的 `EzEMR.html`。
2. 按「開啟既有病歷資料夾」，或「檔案 → 開啟病歷資料夾」，選取本資料夾。
3. 搜尋 `DEMO-` 並選取個案，即可檢視病人總覽、編輯復健紀錄或比較成效。

儲存會修改本資料夾中的檔案；若想保留原始示範資料，請先複製一份再操作。真實病歷請另選空資料夾。

This folder contains eight entirely fictional clients: stroke, traumatic brain injury, double vision, vision loss in one eye, visual field loss, neglect, motor impairment, and spinal cord injury. Each has a baseline assessment, a treatment visit, and a post-rehabilitation assessment: 24 records with CSV, PDF, and TXT files for trying EzEMR. The contents are not clinical guidance.

1. Open `EzEMR.html` from the parent folder in desktop Chrome or Edge.
2. Choose **Open an existing record folder**, or **File → Open record folder**, and select this folder.
3. Search for `DEMO-` and select a client to view the dashboard, edit records, or compare outcomes.

Saving changes modifies this folder. Copy it first to keep the original examples. Use a separate empty folder for real records.
